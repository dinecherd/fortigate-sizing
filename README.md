# FortiGate Sizing Guide

Comparateur et outil de qualification FortiGate, en une seule page HTML autonome.

- **Comparateur** : 31 appliances (30G → 7121F), matrice, barres animées, carte de positionnement, face-à-face jusqu'à 4 modèles avec radar et lien de partage.
- **Qualification** : recalcul en direct, règle des 65 % de charge datasheet, facteur dimensionnant, top 3, bundle FortiGuard, Security Fabric, équivalence concurrente (Palo Alto, Check Point, Cisco, Sophos).
- **Guide d'entretien** : 12 questions à poser au client.
- **Sources** : chaque valeur provient de la datasheet officielle Fortinet du modèle (collecte : 16 octobre 2026).

Outil indépendant, non affilié à Fortinet, Inc. Toujours valider la proposition finale avec un SE Fortinet.
